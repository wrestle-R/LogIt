# LogIt 0.3.1

- Default phone history is 19 weeks and fits the screen.
- Widgets always show recent history that fits their width. Removed the timeframe picker and scrolling collections.
- Multiple activities use fixed tiles. Resize a small widget to reveal more activities.
- Undo can reverse successive logs recorded on this device, including after syncing or restarting. Existing single-log Undo records migrate automatically.
- The website dashboard puts activities first, keeps Log below the graph, fits graphs to the available width and includes Undo on each activity.

Android build, eight JVM tests, web production build and ten web tests passed. Physical phone check added two Guitar logs then used Undo twice, restoring the original count. Website fixture checks passed at 375, 768 and 1440 pixels, with light theme, timeframe selection and repeated Undo.

Multi-activity widget minimum/expanded sizes and offline reconnection still need full physical-device checks. Logs from before device-local history existed cannot be reconstructed into the native Undo stack.
