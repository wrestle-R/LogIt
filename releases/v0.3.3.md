# LogIt 0.3.3

- Forgot to log yesterday? Pick it up from the activity card, choose another date if you need to, or undo a log.
- Set a daily or weekly goal and see how close you are. Weeks run Monday through Sunday.
- Turn on reminders if you'd like a heads-up in the evening or a note the next morning.
- Open More options to see your statistics or check for the next update.
- The Android dashboard has a softer textured background. Widgets stack when there's space for it.
